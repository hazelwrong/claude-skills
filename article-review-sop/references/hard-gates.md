# 硬闸门 HG-1 ~ HG-6（完整判定标准）

命中任意一条，直接判「不发布」，进入不发布待优化库，不看总分、不用高分抵消。判定硬阻断时必须写出具体证据（引用原文片段、缺失字段、矛盾位置），不能只写结论。

| 编号 | 硬闸门 | 判定标准 | 去向 |
|---|---|---|---|
| HG-1 | Google 抓取/理解失败 | 页面不可访问、noindex/robots/canonical 错误、正文主体不可渲染、Schema 与页面主体严重矛盾 | 不发布待优化库 |
| HG-2 | 站内同意图重复 | 与已发布文章服务同一搜索意图，标题/大纲/结论/商品逻辑高度相似，无法说明独立价值 | 不发新文，更新旧文或重设角度 |
| HG-3 | 无信息增量 | 只是复述已有内容、SERP 常识、竞品内容或模板话术，没有新增数据、分析、场景或决策价值 | 打回重写 |
| HG-4 | 内容整体质量失效 | 读者读完仍无法做选择；大量空话、复读、模板痕迹；核心承诺未兑现 | 整体重写 |
| HG-5 | 商品/数据主体失效 | 商品卡严重不足，链接无法落到具体商品，关键数据缺失导致推荐结论不成立 | 补商品/补数据后重跑 |
| HG-6 | 合规/版权/信任高风险 | IP 禁词、YMYL 不当声明、竞品/未授权图片、虚假体验/作者身份、大量 prompt 或调试字段暴露 | 合规修复或下线重做 |

## 执行口径

- 硬闸门是**真的有问题才不能发**，不要把 TD 过长、词数不够、UTM 缺失、alt 不够描述性这类局部小问题扩大成硬阻断——这些属于软闸门标签（见 tags-and-post-publish.md）。
- 命中多条 HG 时，全部列出，不要只报第一条就停。
- HG-1（抓取/理解失败）和 HG-6（合规/版权）通常需要看到渲染后的实际页面或 HTML/Schema 源码才能判断；只有正文文字而没有页面信息时，这两条要标注"信息不足，需人工复核"，不要臆测页面能不能被抓取。
- HG-2（同意图重复）需要知道站内是否已有同选题文章；没有这个信息时同样标注信息不足，不要凭标题猜测是否重复。
- HG-3（无信息增量）和信息增量评分模块是同一套判断标准，参见 scoring-rubric.md 的信息增量四级判定——先判断增量水平，无增量才归入 HG-3。

## 引用来源与出站链接检查口径

引用来源和出站链接既进入 HG-1/HG-6 的硬阻断判断，也进入软标签体系：

| 检查项 | 硬阻断 | 软标签/扣分 |
|---|---|---|
| 来源权威性 | 伪造来源、无法访问来源、来源与论断明显无关 | 来源一般但可验证；建议换更权威来源 |
| 引用方式 | 整段改写或拼接其他来源且没有新增价值 | 引用前缺少本文自己的论断；来源说明不够清楚 |
| 出站链接安全 | 导向竞品商业页、垃圾站、恶意页、错误商品或误导页面 | 非关键链接失效、缺 UTM、锚文本不够清楚 |
| 结构化证据 | Schema 引用内容与页面可见内容冲突或误导 | 推荐属性缺失、来源日期缺失 |

原则：引用支撑论断、帮助读者，避免竞品导流和垃圾外链。
