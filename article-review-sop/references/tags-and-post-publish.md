# 软闸门标签、上线后触发与标签关闭

软闸门不是放过问题，而是把问题标准化成可排期的优化标签。只要不影响 Google 理解页面，也不导致内容整体失效，就允许上线后修——但每个标签必须有 owner、SLA、修复建议和复查范围，不能只写"建议优化"这种没法排期的话。

## 软闸门标签组与默认 SLA

| 标签组 | 典型问题 | 默认 owner | SLA |
|---|---|---|---|
| TD 优化 | Title 过长、Description 不完整、移动端展示不佳 | SEO/编辑 | 普通 7 天，P0 3 天 |
| 页面结构轻微优化 | 面包屑与 Schema 轻微不一致、可选 Schema 字段缺失 | 技术/组装 | 7 天 |
| 信息增量增强 | 已有增量但不够强，缺案例、缺对比、缺具体场景 | 编辑/SEO | 7 天或进入专题优化 |
| 引用与出站链接 | 引用来源不够权威、缺来源日期、出站链接需要补充或清理、引用链接指向竞品 | 编辑/SEO | 7 天 |
| 商品数据增强 | 数据密度偏低、非关键数据需刷新、推荐理由可更具体 | 商品/内容 | 7 天 |
| 运营归因 | UTM 缺失、渠道参数不统一 | 运营 | 批量任务 |
| 图片与视频 | alt 不够描述性、图片重复、缺视频或视频质量一般 | 编辑/素材 | 低优先级优化池 |
| 内链与排版 | 相关文章相关性一般、排版轻微拥挤、CTA 可优化 | SEO/编辑 | 7–14 天 |

每个标签落地时用这个结构：`{标签组, owner, sla, fix（具体修复建议）, 复查范围}`。

## G5：上线后触发来源

已发布文章（发布无问题库 / 发布后待优化库）持续被这五类信号触发复查：

| 触发来源 | 触发条件 | 进入标签 | 处理方式 |
|---|---|---|---|
| 审核软标签 | 发布时已存在 TD、UTM、alt、引用、内链、信息增量增强等标签 | post_publish_opt | 按 owner 和 SLA 修复 |
| Search Console | 收录异常、展示低、点击率低、排名停滞或下降 | data_triggered_opt | 判断是 TD、意图、内容增量还是技术问题 |
| 用户/转化数据 | 停留短、跳出高、商品点击低、转化低 | conversion_opt | 优化商品卡、CTA、对比和决策内容 |
| 人工抽检 | 上线后发现合规、版权、重复、质量异常 | manual_review | 轻微问题后改，严重问题下线或转不发布待优化库 |
| 周期复盘 | 周/月度查看低分模块和高频标签 | batch_fix | 批量修模板、词库、商品数据或组装规则 |

## G6：标签关闭条件

每个标签都必须有明确的关闭条件，否则「发布后待优化库」会变成问题堆积池，而不是优化流程。回答"这个标签能不能关"时，逐条对照下表判断，不要笼统说"看起来改了就行"。

| 标签类型 | 关闭条件 | 复查范围 |
|---|---|---|
| TD 优化 | Title/Description 已改，移动端展示不截断或截断不影响语义 | G1/G6 |
| 信息增量增强 | 新增数据、案例、对比、场景或决策建议，信息增量分提升 | G2/信息增量模块 |
| 引用与出站链接 | 来源可访问、权威且支撑论断；风险外链已移除或替换 | 来源链接模块 |
| 商品数据 | 商品卡、链接、价格、评分、规格、数据日期满足文章结论 | 商品数据模块 |
| 站内重复 | 已合并旧文、重设角度或明确内链层级，避免同意图竞争 | G0/G3 |
| 合规信任 | 风险词、版权图、虚假体验、生成痕迹已清除 | 合规信任模块 |

关闭之后：

- **标签关闭 + 分数提升** → 留库，表现突出的可升级为标杆案例，回流「发布无问题库」。
- **标签未关闭，或质量恶化** → 归档或重写，回到 G0/G1，从头走一遍完整流程（不是直接改完就当发布无问题库处理）。

## 四类流转库速查

四个库不是孤立表格，而是同一篇文章在不同阶段的状态视图。

| 库 | 进入条件 | 是否上线 | 下一步动作 | 典型标签 |
|---|---|---|---|---|
| 成功发布库 | 无硬阻断，允许上线；包括无问题和待优化两类 | 是 | 记录 URL、版本、审核分、软标签、上线时间 | published, live |
| 发布无问题库 | 无硬阻断，总分较高，软标签为空或仅低优先级 | 是 | 作为优质案例、模板样例和内链候选 | clean_publish, benchmark |
| 发布后待优化库 | 无硬阻断，但有软闸门标签、弱项分数或上线后数据触发 | 是 | 按 owner 和 SLA 修复，复审后关闭标签 | post_publish_opt, soft_tag |
| 不发布待优化库 | 命中硬闸门，或分数过低，或人工判定整体质量失效 | 否 | 回到选题、重写、补数据、合规或组装阶段 | not_publish, hard_block |
